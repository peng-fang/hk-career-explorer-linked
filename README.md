# 香港就业市场探索器 · 三页联动版

嘉宁先了解两地就业市场，再用专业、工作兴趣和技能探索香港的「行业 × 职业组」。她把选中的方向带入预算，检验工资、工时和月结余条件。

**[简体中文](https://peng-fang.github.io/hk-career-explorer-linked/?lang=zh-Hans)** · **[English](https://peng-fang.github.io/hk-career-explorer-linked/?lang=en)** · **[三页版 15 分钟演示](docs/三页版_15分钟演示.md)**

## 图表联动

- **00 两地对照**。两张年龄图共享地区高亮，可点图例或条形切换。行业年龄图可选早期和较新两个时期。深港月薪表的人民币和港元列随汇率更新。
- **01 发现方向**。页首先看全港和八个行业的就业人数，并对照行业就业占比。行业菜单、图例和色带可同步切换两图，点 2016–2025 年的数据可更新同年的全港雇佣身份和职业构成。随后填写求职背景，到招聘区筛选行业和职业组。招聘数据按行业大类统计。
- **02 试算个人条件**。沿用 01 页的行业筛选，联动工资、工时、用工走势及候选表。可以暂时展开全部行业和已确认方向。预算表使用用户填写的 Offer 和开支，点月薪中位数可更新 Offer。候选表由 01 页确认的行业与职业组合生成。

## 浏览与演示

1. 打开 `index.html` 即可浏览，网页为纯静态文件。
2. 在 00 页看两地就业年龄结构和青年失业率，再用深港月薪表参考行业工资。点页尾入口进入 01 页，使用嘉宁的示例或填写自己的背景。
3. 在 01 页载入嘉宁的背景或自行选择。点招聘热力格并加入比较，在同页确认清单。可选填想在面试中询问的事项。
4. 在 02 页改工资、工时或预算，查看对照结果。点月薪中位数可以带入预算。
5. 顶部可切换语言。选择、备注及预算保存在当前浏览器标签页的会话内。点「数据来源与使用说明」可核对调查时期和口径。

## 数据与可复现性

网页数据来自《香港劳动力_整合数据集_三页探索版.xlsx》的原项目数据和「00_新增官方数据」。新增指标的来源和覆盖范围可在数据页及工作簿的「00_指标可比性」核对。香港招聘用 2026Q2 数据，预算中使用 2016–2025 年香港全职雇员工资与工时分布。原项目两地行业年龄对比含估计与分类合并。

仓库的 `data/hk-industry-earnings.csv` 还保留香港政府统计处《综合住户统计调查》2008–2025 年分行业的女性、男性和男女合计月收入中位数。 [政府统计处表 210-06316](https://www.censtatd.gov.hk/en/web_table.html?id=210-06316) · [官方原始 CSV](https://www.censtatd.gov.hk/data/MDT_55_210-06316_MDNMEEEM_Raw_hkd_d.csv)

年度失业率来自香港政府统计处，提取在 `data/hk-annual-unemployment.csv`。中年就业人口走势、九个教育序列及行业男女就业人数由整合工作簿导出。 [年度失业率表 210-06101](https://www.censtatd.gov.hk/en/web_table.html?id=210-06101) · [行业就业人数表 210-06305](https://www.censtatd.gov.hk/en/web_table.html?id=210-06305)

可用 Python 与 openpyxl 从含「00_深港行业工资」工作表的整合数据集及上述 CSV 重新生成 `data/guide-data.js`。

```sh
python scripts/export_data.py "/path/to/香港劳动力_整合数据集_深港工资扩展版.xlsx"
```
