# 香港就业市场探索器 · 三页版

嘉宁先了解两地就业市场，再用专业、工作兴趣和技能探索香港的「行业 × 职业组」。她把选中的方向带入预算，检验工资、工时和月结余条件。

**[简体中文](https://peng-fang.github.io/hk-career-explorer-v2/?lang=zh-Hans)** · **[English](https://peng-fang.github.io/hk-career-explorer-v2/?lang=en)** · **[三页版 15 分钟演示](docs/三页版_15分钟演示.md)**

## 浏览与演示

1. 打开 `index.html` 即可浏览，网页为纯静态文件。
2. 在 00 页看两地行业年龄构成、各地青年失业率及同口径的男女劳动参与率。各地行业收入可以展开查看。
3. 在 01 页载入嘉宁的背景或自行选择。点招聘热力格并加入比较，在同页确认清单。可选填想在面试中询问的事项。
4. 在 02 页改工资、工时或预算，查看对照结果。点月薪中位数可以带入预算。
5. 顶部可切换语言。选择、备注及预算保存在当前浏览器标签页的会话内。点「数据来源与使用说明」可核对调查时期和口径。

## 数据与可复现性

网页数据来自《香港劳动力_整合数据集_三页探索版.xlsx》的原项目数据和「00_新增官方数据」。新增指标的来源和覆盖范围可在数据页及工作簿的「00_指标可比性」核对。香港招聘用 2026Q2 数据，预算中使用 2016–2025 年香港全职雇员工资与工时分布。原项目两地行业年龄对比含估计与分类合并。

可用 Python 与 openpyxl 从三页探索版数据集重新生成 `data/guide-data.js`。

```sh
python scripts/export_data.py "/path/to/香港劳动力_整合数据集_三页探索版.xlsx"
```

页面布局与就地筛选参考组员的项目，章节、图表代码和筛选流程在本仓库独立实现。嘉宁为虚构人物，港景封面由图像生成工具制作。 [Hong Kong Job Market Explorer](https://github.com/ketianli082-stack/hong-kong-job-market-explorer)
